# VetCare React

Demo comercial de uma clínica veterinária feita em React + Vite.

## Rodar

```bash
npm install
npm run dev
```

Depois abra a URL do Vite, normalmente http://localhost:5173

## Build

```bash
npm run build
```

## Personalizar

Edite somente:

`src/data/clinic.js`

Ali estão nome, telefone, WhatsApp, endereço, horários, serviços, equipe e depoimentos.

O projeto usa React de verdade, com componentes separados em `src/components/`.
